# SyDown

SyDown is a native Android media downloader built with Kotlin and Jetpack Compose.

تنزيل الوسائط على أندرويد بواجهة بسيطة وحديثة، مع تنفيذ التحليل والتنزيل محليًا على الجهاز.

## Features

- Video and audio downloads
- Multiple available video qualities
- Audio-only downloads
- Download progress, speed and ETA
- Background downloads
- Download cancellation
- Download history
- Arabic and English interface
- RTL and LTR support
- Dark Glass-inspired interface
- Android Share Sheet integration
- Public and Owner editions

## Supported Platforms

Support is tested and maintained for:

- YouTube
- Facebook
- Instagram
- TikTok
- Telegram

Platform compatibility may change when third-party services change their websites or APIs.

## Technology

SyDown is built with:

- Kotlin
- Jetpack Compose
- yt-dlp
- FFmpeg
- youtubedl-android

Media analysis and downloading are performed locally on the Android device.
